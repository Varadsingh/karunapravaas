# मोफत प्रकाशित करण्यासाठी (GitHub Pages)

1. GitHub वर account तयार करा किंवा sign in करा.
2. नवीन public repository तयार करा, उदा. `karuna-travel-blog`.
3. या folder मधील **सगळ्या files आणि folders** repository च्या root मध्ये upload करा.
4. Repository Settings मध्ये Pages section उघडा.
5. `main` branch आणि `/ (root)` निवडून deployment सुरू करा.
6. मिळालेली site link share करता येईल.

> GitHub ची screen/layout वेळेनुसार बदलू शकते; Pages settings मधील static site deployment हा उद्देश आहे.

जर Blogger/WordPress/Notion स्वरूप हवे असेल तर याच मजकुराचे platform-specific version वेगळे तयार करता येईल.
