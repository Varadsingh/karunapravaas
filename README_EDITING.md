# करुणा परदेशी – दुबई–अबुधाबी प्रवास ब्लॉग

हा एक साधा static blog आहे. कोणत्याही paid software ची गरज नाही.

## ब्लॉग पाहण्यासाठी
`index.html` वर double-click करा. Chrome / Edge / Firefox मध्ये ब्लॉग उघडेल.

## मजकूर edit करण्यासाठी
- मुख्य पान: `index.html`
- दिवस १: `day-1.html`
- दिवस २: `day-2.html`
- दिवस ३ ते ६: `day-3.html` ... `day-6.html`
- रंग/डिझाइन: `assets/css/style.css`

HTML फाइल Notepad, VS Code किंवा कोणत्याही text editor मध्ये उघडून मजकूर बदलता येतो. Marathi text Unicode मध्ये आहे.

## दिवस १ आणि २
दोन्ही पानांची placeholder फाइल आधीच आहे. नंतर दस्तऐवज मिळाल्यावर त्यांचा मजकूर आणि फोटो जोडता येतील.

## मोफत online publish करण्याचा सोपा मार्ग
हा folder जसाच्या तसा static hosting वर upload करता येतो. GitHub Pages सारख्या static hosting सेवेसाठी `index.html` root मध्ये ठेवला आहे.

## फोटो
मूळ Word दस्तऐवजातील फोटो `assets/images/day-3` ते `day-6` मध्ये web-friendly WebP स्वरूपात ठेवले आहेत.

## पुढील अपडेट
Day 1 आणि Day 2 documents दिल्यावर हाच ब्लॉग update करता येईल; बाकी design बदलण्याची गरज नाही.
